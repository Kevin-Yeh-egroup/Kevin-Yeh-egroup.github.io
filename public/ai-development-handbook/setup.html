開工設定

今天只做一件事：打開 Codex，請它說出目前開的是哪個資料夾。前置條件：有團隊允許的帳號，以及 Kevin 給你的練習資料夾。第一次可以請 Kevin 坐在旁邊。

  1. 打開 Codex，用團隊帳號登入
  2. 開啟 Kevin 給的練習資料夾
  3. 貼上第一句話
  4. 後｜Codex 說出的資料夾名稱對得上
  1. 打開 Codex 桌面 App，用團隊允許的帳號登入。
  2. 在 Codex 選擇開啟 Kevin 給你的練習資料夾，把它想成一張練習用的工作桌。
  3. 複製「第一句話」，貼到聊天送出。
  4. 和 Kevin 一起看回覆。資料夾名稱對得上，就進下一課。
  5. 要到 GitHub 練習時，再準備自己的 GitHub 帳號、練習專案連結與操作權限，不用一開始全部備齊。

帶教備註

設定卡先填前三行就能開始第一堂，其餘欄位在接正式任務前補齊；IT 窗口、通知管道與時機一律以這張卡為準。Git 用來記錄修改，Node.js 用來跑本課程的小測試，版本依專案 README。Git 提交身分使用團隊認可的姓名與電郵。只有需要讓 Codex 從終端操作 GitHub 時才加裝 GitHub CLI，並以官方登入流程登入後核對帳號。Claude Code 等做到複核或設計時，再依團隊允許的帳號、方案與資料範圍安裝。憑證依團隊方式設定，練習一律使用假資料。
