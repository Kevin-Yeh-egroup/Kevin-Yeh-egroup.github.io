離線搜尋練習

想像你在找一門課：貼上「入門」時前後多了空白，就找不到「程式入門」。這堂課把這個小問題做出來，並親眼看一次預期中的失敗。前置條件：一個空的練習資料夾、Git 和 Node.js 可用、已貼過常駐工作指令。全程在自己的電腦完成，不需要網路。

  1. 空的練習資料夾
  2. Codex 建立搜尋小程式與測試
  3. 跑測試
  4. 後｜一般搜尋：通過
  5. 前｜帶空白搜尋：失敗（預期中，第 6 課修好）
  1. 貼「先確認能開始」，等 Codex 回答可以開始。
  2. 貼「建立練習小題」。
  3. 看測試結果：一項通過、一項失敗，這就是我們要的起點。
  4. Codex 說缺少 Git 提交身分時，請 Kevin 協助設定。
先確認能開始（貼給 Codex）
看完整指令
我第一次練習。請先確認這是空的練習資料夾，幫我檢查 Git 和 Node.js 能不能用。用一句話告訴我能不能開始練習。
建立練習小題（貼給 Codex）
看完整指令
請在這個空資料夾初始化本機 Git，初始分支用 main。建立 search.cjs，匯出 search(items, query)，起始實作使用 items.filter(item => item.includes(query))。另建 search.test.cjs，用 Node 內建測試模組驗證兩種輸入都應找到「程式入門」：一種是「入門」，一種是前後帶空白的「  入門  」。執行 node --test search.test.cjs，先保留帶空白測試的失敗。只把起始程式提交到 main，保留尚未提交的測試檔。練習工單用 LOCAL-1。

過關畫面 一般搜尋通過，帶空白搜尋失敗。main 上只有起始程式，測試檔還留在工作區沒有提交。看到這次預期的失敗就有收穫。

帶教備註

這堂刻意先留下一個會失敗的測試，讓新人之後能示範「修改前失敗、修改後通過」。不要讓 Codex 在這一課就把它修好。練習不安裝任何套件，只用 Node 內建測試模組。LOCAL-1 是離線練習用的工單代號，正式流程改用實際 Issue 編號。
